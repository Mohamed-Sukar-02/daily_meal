Task: Fix Spin Wheel Audio and Haptics

The user wants the spin wheel tick sound to respect the device's Silent mode (so it is muted when the phone is on silent), and wants a stronger haptic feedback. We have added the udioplayers package and the asset ssets/audio/tick.wav.

Follow these exact steps in lib/features/home/presentation/widgets/spin_wheel_dialog.dart:

1. Import Audioplayers
Add import 'package:audioplayers/audioplayers.dart'; at the top.

2. AudioPlayer State & Context Setup
In _SpinWheelBottomSheetState, declare:
`dart
final AudioPlayer _audioPlayer = AudioPlayer();
`
In initState(), right after super.initState(), configure the audio context to respect silent modes:
`dart
_audioPlayer.setAudioContext(AudioContext(
  android: AudioContextAndroid(
    usageType: AndroidUsageType.assistanceSonification,
    contentType: AndroidContentType.sonification,
    audioFocus: AndroidAudioFocus.none,
  ),
  iOS: AudioContextIOS(
    category: AVAudioSessionCategory.ambient,
    options: const {AVAudioSessionOptions.mixWithOthers},
  ),
));
`
In dispose(), add _audioPlayer.dispose(); before super.dispose();.

3. Trigger Custom Audio and Stronger Haptics
In the _spin() method's _animation..addListener(() { ... }) block, replace:
`dart
HapticFeedback.selectionClick();
SystemSound.play(SystemSoundType.click);
`
with:
`dart
HapticFeedback.lightImpact();
_audioPlayer.play(AssetSource('audio/tick.wav'), mode: PlayerMode.lowLatency);
`
(Note: AssetSource automatically prepends ssets/, so udio/tick.wav is correct for ssets/audio/tick.wav).

Make ONLY these changes. Do NOT commit the changes.
